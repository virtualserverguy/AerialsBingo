How It Works

1

Set Up Volunteers

Use the Volunteer Manager to add volunteers and specify how many shifts each person needs to work.

2

Create Shift Schedule

Use the Shift Builder to define your bingo nights with required roles (caller, manager, workers, etc.).

3

Collect SignupGenius Data

Have volunteers sign up using SignupGenius, then export the signup data as CSV.

4

Verify Compliance

Run the verification tool to check who's met their requirements and which shifts need coverage.

📋 Python Verification Tool

After exporting your data files, run the verification script:

python verify_shifts.py --signupgenius data/signupgenius_export.csv
